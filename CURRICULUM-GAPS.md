# Curriculum gaps

Regenerated by `tools/gap-check.mjs`. Run it yourself for any language:

```
node tools/gap-check.mjs Telugu
node tools/matcher-check.mjs Telugu     # does the grader accept the answers the course declares correct?
node tools/autoplay.mjs Telugu --strict # can a learner who only says what it was taught finish every lesson?
```

A drill is **blocked** when even the easiest answer the course accepts needs a
word no lesson has taught by that point. The check is cumulative and
order-aware — at lesson N the learner knows every word and every `alt` spelling
from lessons 1..N — and it scores the easiest accepted form, since that is all
the learner has to produce.

This supersedes the earlier hand-written version of this file, which checked each
lesson against its own vocabulary only and so reported words as untaught that an
earlier lesson had taught (it flagged `illu` as missing in lesson 7; lesson 3
teaches it).

class of problems Telugu had — chiefly a missing copula, which for Hindi is
`hai`/`hoon`/`hain` and for Odiya `achi`/`achhi`/`achhanti`, and which between
them block most of the counts above. Odiya additionally romanises its copula
three different ways for the same verb, so the grader reads the variants as wrong
answers; pick one spelling per form before anything else.
